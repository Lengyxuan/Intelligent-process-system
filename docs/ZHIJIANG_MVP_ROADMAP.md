# 智匠系统 MVP Roadmap

## 改造目标

智匠系统 MVP 的目标是把现有文本 RAG 底座迁移到制造工艺规划场景，先形成“工艺需求输入 -> 工艺知识检索 -> 工艺方案生成 -> 方案审核准备”的可演示闭环。

## 基线原则

- 保留原 ARPM 检索底座，不删除 RAG、向量召回、BM25、RRF、日志与知识库接口。
- 前端完全替换为智匠系统工作台，不再以原产品定位作为主界面。
- 当前阶段只做文本工艺 RAG 闭环，不实现复杂工艺链路。

## 第一阶段：文本工艺 RAG 闭环

- 使用现有知识库上传、分块、检索与生成链路。
- 前端展示工艺需求输入区、工艺知识检索结果区、工艺方案生成区、方案评估区和专家审核区。
- 将生成按钮、页面标题、说明文案统一为智匠系统。
- 保持 `/api/chat` 和 `/api/knowledge` 兼容，避免破坏现有检索能力。

## 第二阶段：工业输入 MVP

- 加入文件格式初判。
- 支持 PDF、PNG、CAD 输入的占位流程与上传 MVP。
- 建立模型父节点和视图子证据的基础数据结构。
- 将文本工艺检索扩展为“文件输入 + 文本需求”的联合入口。

## 第三阶段：图纸与多视图增强

- 加入图纸预处理。
- 加入视图识别。
- 加入多视图图像检索能力。
- 将文本召回与图像召回融合，为后续工艺案例检索和方案评估提供证据。

## 暂不实现

- CAD 几何解析
- 图纸识别完整链路
- DINOv2 / YOLO / OpenCV 工程化接入
- PDF 深度解析
- ProcessSim 工艺相似度重排
- 自动工艺评分闭环
- 专家审核与知识库反哺闭环
